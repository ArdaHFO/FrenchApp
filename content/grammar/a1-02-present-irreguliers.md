# Présent — dört temel düzensiz fiil

Bu dört fiil Fransızcanın iskeletidir. Hem tek başlarına çok kullanılırlar
hem de başka zamanların kurulmasında yardımcı görev alırlar. Ezberlemeye
değer.

## être — olmak

| Şahıs | Çekim | Okunuş |
|---|---|---|
| je | suis | /sɥi/ |
| tu | es | /ɛ/ |
| il / elle | est | /ɛ/ |
| nous | sommes | /sɔm/ |
| vous | êtes | /ɛt/ |
| ils / elles | sont | /sɔ̃/ |

`tu es` ve `il est` aynı okunur.

## avoir — sahip olmak

| Şahıs | Çekim | Okunuş |
|---|---|---|
| j' | ai | /e/ |
| tu | as | /a/ |
| il / elle | a | /a/ |
| nous | avons | /a.vɔ̃/ |
| vous | avez | /a.ve/ |
| ils / elles | ont | /ɔ̃/ |

**Dikkat:** `je` değil `j'ai` yazılır. Sesli harfle başlayan fiilden önce
`je` kısalır.

## aller — gitmek

| Şahıs | Çekim |
|---|---|
| je | vais |
| tu | vas |
| il / elle | va |
| nous | allons |
| vous | allez |
| ils / elles | vont |

Mastar `aller` ama çekimi `v-` ile başlar. Bu tuhaflığın tarihsel sebebi
var, kural aramaya gerek yok.

## faire — yapmak

| Şahıs | Çekim |
|---|---|
| je | fais |
| tu | fais |
| il / elle | fait |
| nous | faisons |
| vous | faites |
| ils / elles | font |

`vous faites` düzensizdir; `-ez` beklenirdi ama `-tes` gelir. Fransızcada
`vous` çekimi `-tes` ile biten sadece üç fiil vardır: `être`, `faire`, `dire`.

## Neden bu dördü önemli

| Fiil | Yardımcı görevi |
|---|---|
| avoir | Geçmiş zamanın çoğunu kurar: *j'ai mangé* |
| être | Hareket fiillerinin geçmişini kurar: *je suis allé* |
| aller | Yakın geleceği kurar: *je vais partir* |
| faire | Sayısız deyimde geçer: *il fait froid* (hava soğuk) |

## Örnekler

| Fransızca | Türkçe |
|---|---|
| Je suis turc. | Türküm. |
| Nous avons deux enfants. | İki çocuğumuz var. |
| Ils vont à l'école. | Okula gidiyorlar. |
| Il fait beau aujourd'hui. | Bugün hava güzel. |
| Vous êtes prêts ? | Hazır mısınız? |

## Sık yapılan hata

Türkçede "üşüyorum" derken özne bendir. Fransızcada hava öznedir:
**il fait froid** (hava soğuk yapıyor). Kendinden bahsederken ise
`avoir` kullanılır: **j'ai froid** (üşüyorum), **j'ai faim** (acıktım),
**j'ai vingt ans** (yirmi yaşındayım). Bu üçünde de Türkçe "-im" eki
Fransızcada `avoir` ile karşılanır.
